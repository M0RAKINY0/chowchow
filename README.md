# Chowchow Backend

Backend-only multi-vendor food ordering API built with Express, TypeScript, Prisma, PostgreSQL, Redis, Resend, and Sentry.

## Local setup

1. Copy `.env.example` to `.env`.
2. Set the local PostgreSQL connection string and JWT secrets.
3. Install dependencies with `npm install`.
4. Start the API with `npm run dev`.
5. Run tests with `npm test`.

Database migrations, seed data, Redis, authentication, ordering, notifications, and API documentation will be added in the following implementation chunks.
